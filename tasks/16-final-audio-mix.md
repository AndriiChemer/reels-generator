# Завдання 16: Фонова музика і фінальне аудіомікшування

## Мета

Зробити фінальний `final.mp4` готовим для перегляду зі звуком:

- одна інструментальна фонова музика на весь Reel;
- вибіркові SFX із task 15 у відповідних сценах;
- тиша там, де SFX не був створений;
- один AAC audio stream у фінальному MP4.

## Провайдери

- ElevenLabs Music API створює одну фонову інструментальну доріжку.
- ElevenLabs Sound Effects API лишається для коротких SFX сцен.
- Для ключа ElevenLabs потрібні `Sound Effects: Access` і `Music Generation: Access`.

## Що реалізувати

- Розширити audio provider методом `generateMusic`.
- Додати server route для створення музики всього Reel.
- Зберігати музику у `outputs/audio/reels/<reelId>/background.mp3`.
- Зберігати metadata музики в `reel.json`.
- Додати preview і кнопку генерації музики до Reel editor.
- Оновити FFmpeg render: нормалізувати video, зіставити SFX із їхніми
  сценами, зміксувати фон на зниженій гучності та експортувати AAC.

## Критерії приймання

- Музика генерується рівно один раз для всього Reel, не для кожної сцени.
- Музика тільки інструментальна, без голосів і вокалу.
- Відсутній SFX не ламає render: FFmpeg підставляє тишу відповідної довжини.
- Музика й SFX не потрапляють у browser до локального збереження.
- Фінальний MP4 містить video і AAC audio stream.
- `npm run lint`, `npm run build` і `git diff --check` проходять.

## Поза scope

- TTS і діалоги персонажів.
- Автоматичне визначення SFX за відеопікселями.
- Детальний багатодоріжковий редактор гучності.
