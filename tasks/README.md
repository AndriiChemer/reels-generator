# Tasks

Ця папка містить маленькі пронумеровані завдання для AI-реалізації.

Правило роботи:

1. Брати лише одне task-завдання за раз.
2. Перед реалізацією читати `README.md` і файли з `docs/`.
3. Не перескакувати на майбутні фази без явної команди.
4. Не додавати зайві залежності, якщо task цього не вимагає.
5. Після завершення task запускати доступну перевірку: `npm run lint`, `npm run build` або мінімальну ручну перевірку localhost.

Рекомендований перший запит:

```text
Read README.md, docs/* and tasks/01-bootstrap-nextjs-in-place.md. Implement only this task.
```
