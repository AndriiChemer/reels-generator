# Завдання 15: Вибіркова генерація SFX для сцен

## Мета

Додати локальний end-to-end flow для генерації короткого SFX-треку лише для
сцени з явно описаними звуковими подіями.

Це завдання не створює музику для всього Reel, не генерує голос і не змішує
аудіо з фінальним MP4. Це буде наступний етап FFmpeg audio mix.

## Правило вибірковості

Кнопка генерації доступна тільки коли в ручному блоці сцени є `Звук:` і хоча б
одна SFX-подія. Наприклад:

```text
Сцена 1:
@mia наливає чай у чашку. 4 секунди.

Звук:
- 0.8-2.2: реалістичний звук наливання чаю в керамічну чашку
- 2.5-3.0: чашка тихо торкається дерев'яного столу
- без голосу
```

Сцени без ручного SFX не мають створювати окремий API-запит до ElevenLabs.

## Що реалізувати

- Додати `POST /api/reels/[reelId]/scenes/[sceneId]/audio/generate`.
- Викликати поточний `AudioProvider` тільки на сервері.
- Побудувати prompt лише зі SFX cues, без голосу й фонової музики.
- Зберігати файл атомарно у `outputs/audio/scenes/<reelId>/<sceneId>.mp3`.
- Зберігати metadata аудіо в `scenes.json`.
- Віддавати MP3 через поточний локальний `/api/media/...` route.
- Додати в Reel editor кнопку, loading/error state і audio preview.

## Критерії приймання

- API key ElevenLabs не потрапляє в браузер.
- Сцена без явного `Звук:` + SFX повертає зрозумілу помилку без виклику provider.
- Після успіху MP3 відтворюється в браузері з localhost.
- Повторна генерація безпечно замінює попередній файл цієї сцени.
- Metadata містить provider, model, тривалість, шлях, дату та `characterCost`,
  якщо ElevenLabs його повернув.
- `npm run lint`, `npm run build` і `git diff --check` проходять.

## Поза scope

- Глобальна фонова музика всього Reel.
- Автоматичні SFX для кожної сцени.
- TTS, діалоги й voice IDs.
- Додавання SFX у `final.mp4`.
