# 12. Basic UX cleanup

## Goal

Зробити MVP зручним для локальної роботи без розширення scope.

## Scope

Маленькі покращення UI, loading states і error states.

## Files likely changed

- `app/layout.tsx`
- `app/page.tsx`
- `app/characters/page.tsx`
- `app/reels/new/page.tsx`
- `app/reels/[reelId]/page.tsx`
- `components/*`

## Acceptance criteria

- UI українською.
- Є прості loading states.
- Є зрозумілі error messages.
- Кнопки disabled під час активних операцій.
- Layout не ламається на вузькому екрані.
- Не додані великі UI libraries.
